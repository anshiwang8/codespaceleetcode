# UI phase 2 Implementation Plan

**Goal:** Eight brand themes, springy interruptible buttons, an animated group index card, no "How it works" section, and smooth in-page section scrolling.

**Architecture:** Two independent slices with disjoint files. The themes slice replaces the palette source and shrinks the picker. The motion slice changes `globals.css`, the Learn components and one new client helper. The lead owns shared docs and the final checks.

**Tech stack:** Next 16 App Router, React 19, CSS modules, vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-17-ui-polish-2-design.md`

## Global constraints

- Colors in components come from theme tokens; the only exceptions are `--plate` and `--mascot-*`.
- No contrast target in `web/tests/themes.test.ts` is loosened.
- The pre-paint script accepts only token-named properties with hex or `rgb()` values.
- The default theme never loads the catalog; the catalog stays a dynamic import.
- Motion is finite, built from transitions for state changes, and off under reduced motion.
- Monaco, tree targets, editor tabs and splitters are never animated.
- US English, sentence case, icons from `Icon.tsx`.
- Commit locally; do not push.

## Review focus

- A signed-in user whose saved theme was one of the 173 removed presets: every page renders in codebases Light with no flash and no catalog load.
- A saved `favorite_themes` list containing removed IDs: `/api/me/preferences` and Settings neither fail nor show them.
- A press released after 30ms, and a press dragged off the button: the button returns from its current scale without snapping.
- An index link clicked while a previous smooth scroll is still running: the marker follows the latest click.
- A reader with reduced motion: index clicks jump, buttons do not scale, progress bars do not animate.
